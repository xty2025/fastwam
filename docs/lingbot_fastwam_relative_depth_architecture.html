按帧解释：深度图到底干了什么？

1. 当前深度帧 D0

先将相对深度 RGB 归一化并经 Wan VAE 编成 zD0。随后仅遮掉部分 latent block，mask 区域不可直接复制。

Depth DiT 读取 Video token，以 RGB 空间语义恢复被遮区域；只在被遮块上计算 L_mrdm。

2. 未来深度帧 D1:8

经同一个 Wan VAE 获得 zD1:8，再按 continuous flow matching 加噪。

Depth DiT 预测去噪方向，只对未来八帧计算 L_future_depth；第 0 帧不参与未来预测 loss。

3. 防止深度泄漏

Depth query 可以读取 Video、Action 与自身 token；Video 和 Action query 不读取 Depth token。

因此深度是辅助重建/监督信号，不会把未来深度标签直接泄漏给 Video 或 Action 分支。
